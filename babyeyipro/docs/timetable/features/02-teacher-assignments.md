# 02 — Teacher Assignments

`/dos/teacher-assignments`

Teacher assignments are the scheduling source of truth.

## Steps

1. Add assignment:
   - teacher
   - class
   - subject
   - periods per week
   - term/year
2. Save and verify row appears active.
3. Repeat until all classes/subjects are covered.

## Tips

- Missing assignments = generator places 0 lessons.
- Keep `periods_per_week` realistic; this directly drives expected coverage.
- Use archive/history features instead of deleting historical records.
