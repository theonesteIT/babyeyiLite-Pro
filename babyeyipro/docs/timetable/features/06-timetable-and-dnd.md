# 06 — Timetable View and Drag-Drop

## Timetable tab

Shows weekly grid by class/teacher.

## Drag & drop editing

1. Drag a lesson card.
2. Drop into target slot.
3. Backend validates conflicts.
4. If valid, move persists; if invalid, fix target slot.

## Per Class Timetable tab

Use this tab for stream-level overview and master timetable validation.

## Finalizing

After manual edits, always scan conflicts.
