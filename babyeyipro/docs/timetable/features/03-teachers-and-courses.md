# 03 — Teachers and Courses Tabs

## Teachers tab

Set profile constraints:
- max periods per day
- available days
- preferred slots

These constraints guide the generator workload balancing.

## Courses tab

Configure per subject:
- priority (low → critical)
- duration behavior (single/double period)
- lab requirements
- scheduling rules:
  - any time
  - morning only
  - afternoon only
  - custom window

## Best practice

Start with simple rules, generate once, then tighten constraints.
