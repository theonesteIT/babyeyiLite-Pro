# 01 — Getting Started (Timetable)

## Access

1. Login with DOS / School Admin / School Manager account.
2. Open `/dos/timetable`.
3. Confirm term/year selector has expected values.

## First setup checklist

1. Create teacher assignments (`/dos/teacher-assignments`)
2. Configure teachers tab
3. Configure courses tab
4. Configure time settings tab
5. Generate and apply
6. Review conflicts
