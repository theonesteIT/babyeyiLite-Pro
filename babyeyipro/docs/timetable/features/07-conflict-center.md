# 07 — Conflict Center

Conflict Center audits timetable quality and supports auto-fix.

## Common conflict types

- teacher_clash
- lesson_overlap
- rule_violation
- extra_overlap

## Steps

1. Open Conflict Center tab.
2. Run conflict scan.
3. Review grouped conflict list.
4. Use Auto-fix where safe.
5. Re-scan until clean.

## Recommendation

Never skip manual review after auto-fix for critical classes.
