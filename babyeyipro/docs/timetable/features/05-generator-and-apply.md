# 05 — Generator and Apply

## Generate

1. Open Generator tab.
2. Select class(es), term, and academic year.
3. Click Generate.
4. Review coverage output (placed vs expected).

## Apply

1. Accept generated result.
2. Click Apply.
3. Confirm timetable rows now exist in Timetable tab.

## Regenerate

Use regenerate for partial rebuilds after assignment or rules updates.

## Clear

`clear-timetables` removes placed rows (does not delete assignment definitions).
