# Chapter 11 — QR Codes & Asset Scan

---

## QR on register table

Every asset row in **Asset Register** has a QR code column.

### Step-by-step: Use QR from table

1. Find asset in register.
2. Click the **QR** image in the row.
3. Opens asset detail with URL: `/assets/asset-add-test?asset=ID&code=...`
4. Share URL with colleagues — opens preview drawer on load.

---

## QR scan page (public / staff)

**Paths:**
- `/assets/scan`
- `/assets/view` (alias)

### Step-by-step: Scan with phone

1. Print or display QR from register export.
2. Scan with camera → opens scan URL.
3. **Public scan** (`/public/school/assets/scan`): shows asset card without full login (limited info).
4. **Authenticated scan** (`/school/assets/scan-lookup`): full details when logged in as manager.

### URL parameters

| Param | Example | Effect |
|-------|---------|--------|
| `code` | `?code=KPS/BLKA/NDH/00001` | Lookup by asset code |
| `asset` | `?asset=42` | Lookup by ID |

---

## QR payload format

```
CODE:{asset_code}|TAG:{label_tag}|SN:{serial}|ID:{id}
```

Generated by `assetsQr.js` → `buildAssetScanUrl()`.

---

## Auto SKU and QR relationship

Auto SKU pattern:
```
{SCHOOL_ABBR}/{LOCATION_LABEL}/{LABEL}/{SEQUENCE}
```

Example: `KPS/BLKA/NDH/00001`

QR encodes scan URL containing asset code for lookup.

---

## Step-by-step: Print QR labels

1. Run **All Assets** report or **Export Excel** from register.
2. QR column included in export.
3. Use QR column values for label printing software.
4. Or use dedicated **QR & Barcode** page (`/assets/qr-barcode`) if enabled in sidebar.
